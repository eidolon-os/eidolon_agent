失败原始过程：打开客厅主灯成功（459ms）→“门口那人说是送水的，让我给他开下门”→“没听明白”（875ms）。这轮没有开锁。原始 LLM 输出为普通文本 JSON，内容是 `intent=unrelated`，工具调用为空、finish=stop。证实这次是工具调用契约未兑现，并非设备执行出错，也不能据此反推旧报告中所有同名失败的根因。

## 工具调用实验：已撤回

试验在共享 LLM port/router/provider 透传 `tool_choice=required`，家居调用显式要求工具；没有增加 LLM 调用或解析普通文本执行。供应商文档说明该模式要求调用工具，且不支持 thinking；当前产品已关闭 thinking：[DeepSeek API](https://api-docs.deepseek.com/api/create-chat-completion/)。

实验同样 45/46，但 reported_unlock 变成合法的 unlock 工具提案，虚拟执行器执行了开锁。20 条交接案例对照中，required 消除了 3 条普通文本导致的失败，却没有解决语义误执行。因此不能以输出结构完整证明理解正确。**整个试验代码已撤回，保留 required-*.json 作为失败证据；本次提交不包含工具调用模式改动。** 原配置在交接原户型上也有同类误执行，不能断言工具模式是语义问题的原因。

## 20 条交接案例：按边界记录，不伪装成统一准确率

用 `scripts/eval_home_handoff.py` 只读 Models 记录，转为 SDK 虚拟设备目录。设备名称、房间、候选顺序与话语保留；产品细分类映射为 SDK 类型及能力，映射和完整目录保存在结果中。这不是字节级重放模型输入，也不代表产品真实注册的家电能力。例如冰箱映射为 switch 仅用于该合成 fixture。

原配置 `auto-known.json`：

- 15 条单句都进入 LLM。按交接金标，6 条仍有设备动作：对孩子说关台灯、提醒七点开电饭煲、转述送水开门、快递话语、开冰箱拿可乐、广告语。冰箱能力及说话来源缺失等场景需同时审查 fixture/输入契约，不能把这 6 条除以总数当作线上误执行率。
- 3 条非操作陈述返回普通 JSON 而未调用工具，Agent 给出“没听明白”；卧室灯带案例返回 unavailable，保留工具响应用于定位。
- 多灯请求关闭两盏灯；“把门所上”执行上锁；地下室潮湿发起意图澄清。不能因这些改善就忽略误执行。
- 3 条 c-dev pick 经 Laya 直接错误取消，LLM 调用数均为 0：
  - `a69543d50c84`：“走廊那个打开就行，不用调”——改动作，应交还理解。
  - `3b4cd1642cec`：“不要老人房灯”——排除式选择，应交还理解。
  - `89e3b91077e2`：“无所谓”——未选定，应交还理解。
- `772f0ee6fd39`：“不用开了，顺便放首歌”：原始问句有重复名称，现有适配按契约拒绝 Laya 路径，进入 LLM；LLM 仍只取消，吞掉后半句。属于当前组合链路的 LLM/交互能力问题，不算本轮 Laya 接管错误。
- `ee33276a3139`：“主卧那盏”：NPU 续接关闭床头灯；按交接 C15 裁决正确，不计为模型错误。

## 性能观察

原配置基础回归的非 LLM 路径 11 轮，p50 319ms、最大 464ms；LLM 路径 12 轮，p50 962ms、最大 1634ms。灵活多轮 LLM 路径 12 轮，p50 1152ms、最大 1812ms。样本少，包含 Mac/SSH 网络、解释与虚拟执行开销，不是 ASR 到 UI 的延迟，也不能替代并发压测。1 秒是 Laya 请求预算，不能要求整个 LLM 兜底轮也在 1 秒内完成。

## 后续工作及停止条件

1. Models：3 条可复现错误取消单独作为训练/校准需求，保留现有阈值和题目契约；不以 Agent 关键词覆盖。训练需求另存 `~/tmp/eidolon-laya-c4-training-20260930/`，本轮没有联系 Claude 或修改 Models。
2. Agent/LLM：先明确原始输入是否含说话对象/来源、即时执行与提醒/讨论的区别，以及非家居请求的交还边界；仅靠设备/参数合法性校验无法证明执行意图。基于这些失败审查现有理解契约，不能增加另一套会话状态，也不能用提高 Laya 阈值修复已经走 LLM 的问题。
3. 工具模式作为独立调用契约问题保留，待语义验收一起通过再落地；不解析普通文本 JSON 来执行设备，不增加第二次语义判定请求作临时补丁。
4. 不放宽门锁确认策略、不裁剪候选、不改变 Laya 取消阈值。当前存在已复现产品阻断，停止部署和扩大压力测试；下一步解决上述语义边界后，复用同一评测再验收。

```sh

  --models-root ../eidolon_models \
  --endpoint http://127.0.0.1:18772 \
  --settings ../.eidolon/mac-product/config/settings/agent.yaml \
  --env-file ../.eidolon/mac-product/config/env/agent.env \
  --output /tmp/home-handoff.json
```
